🆘 NEED HELP?
─────────────────────────────────────────────────────────────────────────────

If deployment fails:

1. Check QUICKSTART.md "If It Doesn't Work" section
2. View app logs via Log stream in Azure Portal
3. Verify settings: PORT=8080, NODE_ENV=production
4. Restart the app
5. Wait 2-3 minutes for startup

Common issues:
  - Blank page → Check Log stream for errors
  - 404 errors → Verify web.config is deployed
  - Timeout → Wait longer, then refresh
